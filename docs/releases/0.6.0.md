# Mac Gaming Uncle 0.6.0 — Spatial Audio & Steam Lifecycle Preview

Apple Silicon · macOS 15+ · English / 简体中文

## Changes

- Integrates [PR #3 by Tianyulife](https://github.com/enginefuture/mac-gaming-uncle/pull/3) with the latest local Steam lifecycle, download metrics and Wine preparation fixes. The spatial port retains attribution to Switchyard Wine.
- Publishes Wine `11.0.9-services.1` and updates the app's automatic installer to this archive. Publishing the app alone would have left users on `11.0.2` without the spatial patches.
- Base Windows spatial object audio streams render PCM positions and gains through CoreAudio's Spatial Mixer and native device layouts. Corrected per-pass dynamic-object capacity prevents the stream recreation that caused severe stutter in the reported Split Fiction scene.
- Adds retained `IAudioClock`, `IAudioClock2` and `IAudioStreamVolume` services, endpoint invalidation and audio regression tests; per-game spatial diagnostic logs are optional.
- Wine version selection persists across launches. Running or selected app-managed versions are protected from removal; unused versions move to Trash without deleting bottles or games.
- Reads Steam's cloud log and waits for matching account/game upload completion before session restart or shutdown. Pending uploads persist across app launches. Unconfirmed completion leaves Steam running; the app never rewrites save files or Steam cloud metadata.
- Wine preparation retries a timed-out font/display operation once after clearing stale preparation helpers, and records operation-specific diagnostics. Other failures retain their original errors.
- Download speed/verification/pause states, Steam search debounce and stale-response rejection, background library reads, metadata retry, adaptive carousels, and native Window shortcuts.
- Packaging checks support both SwiftPM resource layouts, including Xcode's `Contents/Resources` bundles.

## Upgrade

Quit the previous app, open `Mac-Gaming-Uncle-0.6.0-macOS-arm64.dmg` and drag the app into Applications. Existing games, bottles and saves stay in their current location.

To use the new audio runtime, open Advanced Settings, choose **自动安装最新版本 / Install Latest Version**, quit games and Windows Steam after cloud synchronization, and select Wine `11.0.9-services.1`. An explicitly selected older version remains selected until you change it. The Wine archive is also a separate release asset for offline import.

The DMG includes the app and its Steam helper. Wine downloads separately; Apple D3DMetal remains a user-imported component. Apple binaries, Steam, games and account data are not redistributed.

**Signing:** this is an **ad-hoc signed, unnotarized research preview**, not a Developer ID release. macOS may require an explicit user decision to open it. Do not disable system-wide security protections.

## Validation and limits

- Application regression: 122 Swift tests, 4 external/opt-in skips, 0 failures; Release app/CLI builds, JavaScript bridge checks, Windows fixtures and locked-patch checks pass.
- Both opt-in product tests pass separately against the extracted release archive: import/Bottle initialization with Chinese and space-containing paths, and D3D11/D3D12 fixtures using locally imported GPTK 4.0b2. The package audit reports 38 x86_64 Mach-O files and zero errors; actual Xcode 27 / SDK 27 build provenance is included in the runtime.
- Extracted-archive audio rerun on built-in stereo output: 3,090 spatial checks per PE architecture, zero failures/skips and 2 existing todos each; WASAPI render 4,456 checks, zero failures, 2 skips and 177 existing todos. Endpoint enumeration/property checks also pass. No physical controller was connected for the XInput probe. Detailed results, including the initial failed device run, are in [release validation](../validation/release-0.6.0-20261011.json).
- CoreAudio native-layout helper scenarios pass for 5.1.2, reordered channels, coordinates/device identity, malformed/count mismatch, unknown/discrete layouts, and tag/bitmap expansion.
- PR author evidence: 3,090 spatial checks per PE architecture with zero failures/skips, and a short user-accepted Split Fiction scene on 7.1.4 output. This is prior PR evidence, not a new game acceptance run for this release.
- Physical speaker direction, volume-channel mapping against Windows, device hotplug/sleep recovery and long-duration gameplay remain unverified. HRTF/metadata streams, Dolby Atmos bitstream output and head tracking are not implemented. Stereo content does not become spatial audio automatically.
- An initial run on Bluetooth output failed with endpoint invalidation; that device disappeared during the run and macOS fell back to built-in speakers. This does not validate Bluetooth continuity or recovery. Bluetooth compatibility remains unconfirmed, and these initial failure results are retained separately from the built-in-output rerun.
- Steam owns the actual cloud upload. These protections do not add cloud support to unsupported games or establish successful upload without Steam's matching completion evidence. A real account/game cross-machine cloud round trip has not been revalidated for this release.
- Experimental frame interpolation stays off by default and requires macOS 26. Universal game compatibility and doubled FPS are not promised.

## 中文说明

本版将音频 PR 与我们最新的云同步退出保护、下载状态及 Wine 准备超时恢复合并，并发布包含音频补丁的 Wine `11.0.9-services.1`。只更新应用而继续使用旧 Wine，无法获得空间音频改进。

升级后在高级设置安装最新 Wine，等待云同步完成并退出游戏及 Windows Steam，再选择新版本。无需删除已有游戏、容器或存档。空间音频仍为基础对象音频实现；PR 中《双影奇境》的短场景验收不能代表所有游戏或完整 Atmos 支持。

此版本为 **ad-hoc 签名、未经 Apple 公证的研究预览版**。云存档上传仍由 Steam 完成；未确认上传成功时，应用会保留 Steam 运行。
