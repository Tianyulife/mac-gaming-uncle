# Mac Gaming Uncle 0.5.0 — Steam Downloads & Storage Preview

Apple Silicon · macOS 15+ · English / 简体中文

## What's new

- Background Steam installation through a private inherited-pipe CDP bridge. No public debugging port or copied login cookies.
- Check the actual Steam backend connection as well as the login UI state before installation.
- Prevent install popups from showing or taking focus before display; restore normal behavior when users explicitly open Steam.
- Download progress, downloaded/total size, network speed, pause and verification states. Estimated speed is labeled when a native rate is unavailable.
- Uninstall action with confirmation and a running-game check. Completion requires actual manifest removal while the library remains accessible.
- Storage & Libraries: attach an existing SteamLibrary/steamapps folder or select a new library folder, then choose an installation destination and see available space.
- External Wine drive mappings, offline-library labels and reconnect discovery. A disconnected target does not silently fall back to the internal disk.
- Steam UI scaling corrections and English/Chinese strings for the new flows.

## Installation

Download `Mac-Gaming-Uncle-0.5.0-macOS-arm64.dmg`, open it, and drag the app into Applications. Quit the previous app before replacing it. Quit and reopen the managed Windows Steam once after upgrading so the updated helper can load; installed games and saves do not need to be removed.

The DMG contains the app, not Windows, Steam, games or Apple graphics components. Follow the first-run setup when installing on a new Mac.

**Signing:** this is an **ad-hoc signed, unnotarized research preview**, not a Developer ID release. macOS may require an explicit user decision to open it. Do not disable system-wide security protections.

## Validation and limitations

- 96 Swift tests: 2 opt-in tests skipped, 0 failures; bridge and presentation JavaScript regression tests pass.
- Balatro was installed through the packaged app's library-selection flow. A 40-second observation recorded 2011 owned-window samples with none visible; 4 show/focus requests were blocked and hooks were restored afterward.
- An isolated non-default-library installation of Arrow a Row completed and was discovered at the chosen path. Physical external-disk hotplug and every filesystem/client version have not been tested.
- Steam's private frontend interfaces can change. Login, agreements and exceptional cases may still require the explicit Steam Client entry.
- Avoid concurrent authenticated test Steam clients with the same account: a separate Wine prefix does not isolate the account session.
- Existing experimental frame interpolation remains off by default and requires macOS 26; this release does not promise FPS multiplication or universal game compatibility.
- This release does not automatically migrate already installed games between disks.
